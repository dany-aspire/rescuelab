# P2-004 — Reproducible Demonstration

## Objective

Create a clean-checkout demonstration that produces durable, machine-readable
evidence for the healthy RescueLab baseline.

## Execution

- Actor: `CODEX_EXECUTOR`
- Surface: `CODEX_CLOUD`
- Branch: `phase-2/p2-004`
- Primary deliverables: `docs/demo.md`, a small smoke-test script, and a GitHub Actions verification workflow

## Required work

1. Define one copy-pasteable local demonstration path from clean checkout through
   dependency install, automated checks, Compose build/start, health, list,
   create, reload/persistence, and clean shutdown without deleting the volume.
2. Implement the smallest maintainable smoke-test script that verifies HTTP
   health, listing, creation, and persistence through the public Nginx endpoint.
3. Add a GitHub Actions workflow that runs the repository checks and the
   Compose-backed smoke demonstration on pull requests and manual dispatch.
4. Add browser automation or screenshots only if they can be generated
   reproducibly and maintained safely; otherwise disclose the remaining browser
   evidence gap instead of fabricating it.
5. Use `.env.example` or equivalent ephemeral CI values without committing secrets.
6. Ensure cleanup runs even when verification fails.
7. Do not change application behavior or historical incident artifacts.

## Verification

- Validate shell syntax and workflow syntax.
- Run `npm ci` and `npm run check`.
- Run every feasible smoke step in Codex cloud.
- Treat the GitHub Actions result as required evidence for Docker-backed checks
  that the Codex cloud container cannot execute.
- Confirm generated output contains no credential, personal path, or private marketplace data.
- Run `git diff --check`.

changed file in full in pull request #15. Do not attempt to commit or push.
