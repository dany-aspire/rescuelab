# P2-001 — Portfolio Evidence Audit

## Objective

Audit the public RescueLab repository as evidence for a narrow AI-generated-app
deployment rescue service.

## Execution

- Actor: `CODEX_EXECUTOR`
- Surface: `CODEX_CLOUD`
- Branch: `phase-2/p2-001`
- Deliverable: `docs/portfolio-audit.md`

## Required work

1. Inventory the application, verification commands, RL-001 through RL-008
   tickets, diagnoses, reports, reviews, and workflow documentation.
2. Build a claim-to-evidence table for the important portfolio claims.
3. Identify:
   - unsupported or overstated claims;
   - broken or missing links;
   - inconsistent incident metadata;
   - private, personal, or marketplace material that should not be public;
   - missing evidence that materially reduces portfolio credibility.
4. Recommend the smallest prioritized improvements for P2-002 through P2-007.
5. Separate verified facts from recommendations.
6. Do not rewrite the README, application, incident history, or reports in this
   task.

## Verification

- Confirm every cited repository path exists.
- Confirm the audit does not reveal secrets, hidden incident-injection details
  beyond existing public artifacts, or private freelance-ops information.
- Run `git diff --check`.
- Leave the working tree clean after committing.

## Handoff

When the audit is complete:

1. Commit and push only `phase-2/p2-001`.
2. Update the branch copy of `handoffs/CURRENT.md` to:
   - increment the sequence;
   - `State: WORK_PROPOSED`;
   - `Next actor: CHATGPT_WORK`;

3. Report the audit summary and verification results in the pull request.
4. Stop without merging.
