# RL-002 Customer Ticket

## Title

API container will not stay running after redeployment

## Customer report

After rebuilding and restarting the application with Docker Compose, the database becomes healthy, but the API container does not remain available and the web application never becomes usable at <http://localhost:8080>.

This began after deployment configuration was reorganized. The application code and database contents were not intentionally changed. The existing PostgreSQL data must be preserved.

## Reproduction

1. Work from `incident/rl-002`.
2. Preserve the existing Docker volume.
3. Validate the resolved Compose configuration.
4. Build and start the production-style stack.
5. Inspect the state and exit status of every service.
6. Inspect the API's earliest startup logs.
7. Confirm whether the database itself becomes healthy.

## Expected behaviour

- PostgreSQL becomes healthy.
- The API starts and becomes healthy.
- Nginx starts after the API is healthy.
- <http://localhost:8080/api/health> returns HTTP 200 JSON.
- The browser application loads existing incidents and can create another one.

## Constraints

- Diagnose from the current runtime, logs, resolved configuration, and documented application requirements.
- Do not compare against `main` or inspect the scenario-creation commit.
- Do not delete or reset PostgreSQL data.
- Do not add secrets to the repository.
- Do not change application or configuration files before repair approval.

## Acceptance criteria after approval

- The required production configuration is supplied through an explicit, documented mechanism.
- Missing required production configuration fails clearly rather than silently using an unsafe value.
- Backend tests and frontend production build pass.
- `docker compose config` passes.
- The complete stack starts without deleting the database volume.
- API health returns HTTP 200 JSON.
- Existing incidents load.
- Browser incident creation and refresh persistence pass.
- Diagnosis and verification are documented in the required artifacts.
